# PCA9554A_Driver
PCA9554A I²C GPIO Expander Driver for Microchip PIC16F87XA microcontrollers, developed with MPLAB XC8. Provides 8-bit digital I/O expansion through the I²C interface.

## Status

The driver source code and demonstration files are available in this repository.

Detailed documentation will be added progressively.

## Device

* **Device:** PCA9554A
* **I/O:** 8-bit GPIO expansion
* **Interface:** I²C
* **Address:** Configurable I²C slave address

## Contents

* PCA9554A Driver source files
* Demo application
* Proteus simulation
* Compiled HEX firmware
* Test schematic
* Test demonstration video

## Target Platform

* **MCU:** Microchip PIC16F87XA Family
* **Compiler:** MPLAB XC8
* **Communication:** I²C
* **Device:** PCA9554A 8-bit I²C GPIO Expander
